## 🚀 Tasks Completed

### Task 1 – Iris Flower Classification

**Objective:**
Build a machine learning classification model to identify the species of an Iris flower based on its physical measurements.

**Technologies Used:**

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn

**Work Performed:**

* Loaded the Iris dataset using Scikit-learn
* Performed Exploratory Data Analysis (EDA)
* Checked data shape, data types and null values
* Generated descriptive statistics
* Created visualizations
* Split the dataset into training and testing sets
* Trained multiple classification models
* Compared model performance
* Evaluated accuracy, precision, recall and F1-score
